# Shipment support pilot

**A proposed pilot led by Bahaa Hamdan and Mohamad Nassif**

When an AI agent handles shipment-status or delay enquiries, a support team needs to decide where to use it, where people should keep reviewing answers, and whether an upgrade is worth its cost. We propose starting with one support channel and a clearly defined set of enquiries so we can test how well the evidence answers those questions.

## What we would evaluate

- **Service quality.** Did the agent use the correct shipment, container and milestone based on the records available at the time? Was the enquiry resolved, and did it require a human correction?
- **Effort and cost.** How did the handling approach affect recorded staff time and documented operating costs? Where costs rise, what improvement would justify the increase?
- **Recommended action.** We would explain which action the evidence supports, such as continuing with human review, testing a targeted change, or expanding an eligible group of enquiries. Each recommendation would identify the evidence, the uncertainty and how to check the result.

## What we would ask for first

A 30-minute scoping discussion with the support owner and a data contact. If the workflow is suitable, we would request an authorized, pseudonymized sample of enquiries and replies, historical tracking records and the linked case or agent activity. The company would help confirm what the records mean and independently review selected cases. We would agree on access, retention and review arrangements before receiving any records.

## What the company would receive

A brief assessment of which measures the records support, a set of traceable case findings, and a recommendation about what to test or change next. If the available records support a credible comparison, the next phase can estimate the change in service, staff effort and scoped cost between handling policies.

The current prototype has been demonstrated on synthetic records. The first company sample would test data fit and the accuracy of the checks. A larger, appropriately designed evaluation would be needed before making claims about the deployment’s impact.
