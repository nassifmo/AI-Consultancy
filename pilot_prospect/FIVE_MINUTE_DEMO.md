# Five-minute shipment support pilot demo

Open the local evaluator with `Launch evaluator.cmd`. Run the clean demo once before the call. Use synthetic data throughout.

| Time | What to show and say |
| --- | --- |
| 0:00–0:35 | **Opening.** “We help a shipping support team decide where an AI agent is ready to use, what needs to change, and when an upgrade is worth the cost. The demonstration uses synthetic exports.” |
| 0:35–1:35 | **Prepare company files → Preview synthetic company extract → Save and use prepared files → Run evaluation.** Show how a sample with different source field names maps to the evaluator. Open **Data readiness** and highlight that assignment is unavailable for this sample, so it supports a case review. |
| 1:35–2:20 | **Enquiry evidence.** Open S32. The first reply drew on another container’s discharge event. The human corrected the answer. Show the final resolution alongside the initial critical failure and five minutes of recorded active work. |
| 2:20–3:20 | **Three handling policies · clean demo → Run evaluation → Comparison.** Show 1,108 eligible requests, verified resolutions and unknown outcomes. Point to **Costs and settings** for cost per request and active human time. Explain that a reduction in recorded work can free capacity while a change in spending needs its own evidence. |
| 3:20–4:25 | **Upgrade value → Decision and next action.** Compare Agent v1 with human handling and select verified resolution within 60 minutes. Show the **$9.73** break-even per additional verified timely resolution and point out that missing outcomes could erase the gain. Set the illustrative limit to **1%**. Seven of 348 v1 requests trigger **Review failures and retest**. Show the six identity failures and one escalation failure with their proposed retests. Open **Decision evidence and downloads** to show the source records and brief. |
| 4:25–5:00 | **Close.** Ask for a brief scoping discussion and a small authorized sample of linked records. Explain that the first review would show which measures are viable, which findings require human review, and whether a comparative pilot is justified. |

Avoid presenting the synthetic break-even figure as a willingness-to-pay estimate. For a company sample the shipping team would agree on its service objective, minimum acceptable quality, costs and the value of the outcome or how to measure it.
